A desktop app, not a launcher wrapper

Everything around the game.

SteamTron keeps the pieces Steam leaves scattered — fixes, manifests, prefixes, backups, updates, and the library itself — in one focused surface.

▦

Managed library

Keep a clean record of installed, linked, and downloaded games with independent Home, Library, and Store routes.

◇

Per-game fixes

Apply GoldBerg, Steamless, and an overlay without touching the installed game folder.

◈

Proton runners

Download, verify, and select GE, CachyOS, and Valve Proton runners per game or globally.

◎

IGDB Store

Browse PC titles, filter by genre, and add Steam releases directly to your managed library.

▣

Backups that travel

Per-game content, fixes, manifests, and save snapshots with verification and restore.

◌

Updates + DLC

Pin archived builds, inspect depots, and manage add-ons without leaving the app.

Built for the couch

Before you install

Small print, no surprises.

Does SteamTron include games or keys?

No. SteamTron is a manager. It does not bundle game content, manifests, or license keys. Use it with content you are entitled to run.

What does the Windows preview require?

Windows 10/11, WebView2, Steam, and WinFsp for the overlay. The Windows overlay is under active hardening; the Linux build is the primary target.

Is the IGDB Store a separate account?

The Store uses the SteamTron API to fetch a Twitch/IGDB application token, then queries IGDB directly. Connect IGDB from the API settings page when prompted.

Where is the source?

Desktop source is public on GitHub. The API/website repository remains private. Contributions and bug reports are welcome.
